# 示例架构

框架采用多层分层设计，主要设计是 `基础层` 和 `插件层` 相结合。

- [示例项目](http://git.gksyb.com:3000/gksyb/framework-sample)结构如下：

- **框架通用组件**`Gksyb.Common`：框架核心层，包含一系列快速开发中经常用到的Utility辅助工具功能，框架各个组件的核心接口定义，部分核心功能的实现。
- **框架共用实体**`Gksyb.Model`：实体及实体关联的业务逻辑。
- **框架共用定义**`Gksyb.Core`：共用接口定义、权限拦截、数据库通用处理。
- **业务模块**`Gksyb.Server`：框架默认实现的后台管理系统，包含组织、角色、用户、权限、配置等通用功能（插件式加载）。
- **业务模块A**`XXX.Business`：业务模块（插件式加载）。
- **web主机**`WebHost`：入口层/启动层，加载配置指定的插件。
