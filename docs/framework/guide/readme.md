# 介绍
港口事业部开发框架是一个在项目过程中慢慢积累起来的开发框架。由于时间跨度较长、项目运维周期长等原因，框架以匹配度、易用性、可扩展性为主要原则。

框架提供了一些场景下的解决方案、可加快开发效率，且由于学习相同的技术栈，可使不同开发人员在项目开发协作和后期运维上可交叉工作。

## 🥗 环境要求

- [Visual Studio 2022 +](https://visualstudio.microsoft.com/zh-hans/vs/)（[帮助文档](https://docs.microsoft.com/zh-cn/visualstudio/windows/?view=vs-2022&preserve-view=true)）
- [ASP.NET 6](https://docs.microsoft.com/zh-cn/aspnet/core/?view=aspnetcore-6.0)
